Module Accréditations

Obtenir une accréditation Diaspo'Actif

Certaines rubriques sont réservées aux personnes agréées par Diaspo'Actif. Choisissez l'accréditation qui vous intéresse et faites votre demande : l'équipe vous recontacte, puis vous envoie un code d'activation par message sécurisé.

Comment ça marche ? 1. Vous faites votre demande (téléphone, e-mail, motif). 2. Diaspo'Actif vous recontacte. 3. Vous recevez un code par message sécurisé, valable 7 jours, qui ne fonctionne que sur votre compte et une seule fois. 4. Vous le saisissez ici : l'accès s'ouvre et le module passe au doré. Diaspo'Actif peut suspendre ou retirer une accréditation à tout moment.
